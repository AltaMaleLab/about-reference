About Page — Guide d'intégration Divi

Ce document de référence présente les 12 sections de la page About d'Alta Male Lab, prêtes à intégrer dans WordPress/Divi via des modules Code. Chaque section est un fichier HTML autonome — coller tel quel dans le module Code Divi.

Chaque section est prévisualisée en mode desktop (1440px mis à l'échelle) et mobile (390px réel), avec un bouton pour copier le code et un lien de téléchargement du fichier.

La règle — Un module Code Divi par section

  • Chaque fichier = un seul module Code dans Divi. Coller le contenu entre <body> et </body> uniquement (ou le fichier complet selon la méthode de Laurent)
  • Les styles Divi sont neutralisés par les préfixes de classe scoped (alta-ab-sXX-) et le !important systématique
  • Les polices Google (Poppins + Lato) sont chargées par le <head> de chaque fichier — Divi les chargera une seule fois
  • S07 (About Anthony) contient un portrait encodé en base64 (~3.8 MB) — poids normal, aucune dépendance externe
  • S11 (ALTA & Men's Health) : les liens CTA (href="#") sont à compléter par Laurent avant mise en ligne
Réglages Divi recommandés
Réglage Valeur Note
Module Code Un module par section, pas de Row ni de Column Divi
Background #000000 Désactiver tout background Divi sur la section et la row
Padding section 0px Le padding est géré par le code HTML de chaque section
Gutter width 0 Désactiver les gouttières Divi
Max width 100% Le max-width: 760px est géré en interne
Custom CSS — Ne pas ajouter de CSS Divi — tous les styles sont dans le module
