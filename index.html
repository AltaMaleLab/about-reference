Page About ALTA MALE LAB — rendu attendu et méthode Divi.

Cette page montre les 12 sections de la page About telles qu'elles doivent apparaître sur le site, en desktop et en mobile. Chaque aperçu est produit par le fichier exact à intégrer : ce que tu vois ici, c'est ce que le fichier donne une fois collé.

Elle utilise la même méthode que la page Homepage. Le rendu immersif complet est disponible ici : aperçu About EN →

01 — La règle

Un fichier = un module Code.

Chaque section de la page About = un seul module Code Divi, dans lequel on colle le fichier HTML/CSS correspondant, tel quel.

Aucun module Texte, Titre, Bouton, Image ou Séparateur. Aucun réglage de style Divi (police, taille, couleur, espacement, responsive). Aucun texte retapé.

Tout le design (textes, césures, graisses, couleurs, espacements, version mobile) est déjà dans le fichier. Divi sert uniquement de structure : une section, une ligne, une colonne, un module Code.

Le préfixe de classes CSS est alta-ab-sXX- pour toutes les sections About, évitant tout conflit avec la Homepage.

02 — Réglages Divi

Préparer chaque section.

SectionCouleur de fond #000000. Marges intérieures haut et bas : 0px (chaque fichier gère ses espacements).
Ligne (Row)Largeur 100%, largeur max 100%, marges intérieures 0px, gouttière 1. Le fichier centre lui-même son contenu sur 760 px.
ColonneUne seule colonne par section, marges intérieures 0px. (S07 gère son propre layout 2 colonnes en CSS interne.)
ModuleUn seul module Code, marges 0px. Coller le fichier complet tel quel.
Footer globalDésactiver le footer WordPress standard sur la page About : Page Settings → Divi → Footer → None. La section S12 est la clôture éditoriale — rien après.
En-têteUtiliser la navigation ALTA globale déjà en place (même que la Homepage). Marquer le lien « ABOUT » comme actif (alta-nav__link--active).
Police GaoelGaoel sert uniquement au logo. Elle est déjà intégrée dans l'en-tête global (S00 de la Homepage) : rien à réinstaller. Jamais Gaoel pour les titres ou le texte.
Portrait S07Photo intégrée en base64 directement dans le fichier. Ne pas remplacer par un lien image Divi — le fichier se suffit à lui-même.

Coller sans abîmer le code

  1. Prendre le fichier depuis cette page (bouton « Copier le code » ou « Télécharger le fichier »). Jamais depuis un email ou un document Word : les guillemets seraient modifiés.
  2. Coller dans l'onglet de contenu du module Code, sans rien ajouter ni retirer.
  3. Garder les liens provisoires #journal, #framework, #manifesto, #academy tels quels. Ils seront remplacés quand les pages existeront.
  4. Enregistrer, puis vider les caches : Delete Cache (barre WordPress, WP Super Cache), cache CSS de Divi, et Cloudflare si besoin.
  5. Comparer la section avec son aperçu ci-dessous, en desktop puis en mobile.

Si quelque chose ne s'affiche pas comme ici

Ne pas corriger dans Divi et ne pas modifier le code. Envoyer une capture et une phrase qui décrit ce qui se passe (numéro de section, desktop ou mobile). Un fichier corrigé est renvoyé.
