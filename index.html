01 — La règle

Un fichier HTML/CSS = un module Code Divi.

Chaque section de la page About est intégrée dans un Module Code Divi séparé. Aucun module Texte, Titre, Bouton ou Image Divi n'est utilisé. Tout le contenu et les styles sont dans le HTML/CSS du module.

Règle absolue : ne jamais laisser Divi générer du CSS automatique sur ces sections. Le CSS de chaque module commence par un reset scoped et toutes les propriétés clés utilisent !important.

Structure du module Code pour chaque section :

<!-- ═══ S07 · THE FOUNDER ═══ --> <style> .alta-ab-s07-wrap *, .alta-ab-s07-wrap *::before, .alta-ab-s07-wrap *::after { box-sizing: border-box !important; margin: 0 !important; padding: 0 !important; } /* ... styles spécifiques à la section ... */ </style> <section class="alta-ab-s07-wrap"> <!-- contenu HTML --> </section>
→ Le préfixe de classes CSS est alta-ab-sXX- pour toutes les sections de la page About (ex. alta-ab-s01-, alta-ab-s07-). Cela évite tout conflit avec la Homepage ou d'autres pages.

02 — Réglages Divi

Configuration à appliquer avant d'intégrer.

Sur la page About dans WordPress :

  • Footer global : désactiver sur cette page (Page Settings → Divi → Footer → None). La section S12 est la clôture éditoriale — aucun footer WordPress ne doit apparaître après.
  • Header global : utiliser la navigation ALTA déjà en place (même nav que la Homepage).
  • Fond de page : #000000 — vérifier dans Customize → Body Background.
  • Marges des sections Divi : mettre toutes les marges et paddings Divi à 0 — le padding est géré dans le CSS de chaque module.
  • Largeur des colonnes : toujours une seule colonne par section (sauf S07 qui gère son layout 2 colonnes en CSS interne).
  • Coller le code : dans le module Code, utiliser l'éditeur "Code" (pas "Visual") — ne jamais passer par l'éditeur visuel de WordPress qui encode les balises HTML.

Google Fonts — à charger une seule fois dans le header global (functions.php ou Divi Theme Options → Integration → Add code to the <head>) :

<link href="https://fonts.googleapis.com/css2?family=Poppins:wght@500;600&family=Lato:wght@300;400;700&display=swap" rel="stylesheet">
⚠ Police Gaoel (wordmark "ALTA MALE LAB" dans la nav) : déjà intégrée en base64 dans le fichier HTML de référence et dans la nav globale existante. Ne pas modifier, ne pas remplacer par un lien externe.

05 — Workflow recommandé

Ordre de travail.

  • Ouvrir l'aperçu immersif sur un second écran — c'est la source de vérité visuelle
  • Créer une nouvelle page WordPress "About" (slug : about)
  • Passer en Divi Builder → Build from scratch
  • Désactiver le footer global : Page Settings → Divi → Footer → None
  • Intégrer les sections dans l'ordre S01 → S12, une section = un Module Code
  • Vérifier chaque section sur desktop (1440px) et mobile (390px)
  • Valider la nav active : lien "ABOUT" en état actif dans le menu
  • Valider le rendu final contre l'aperçu de référence
→ En cas de doute sur un détail visuel, l'aperçu immersif fait foi. Référencer la section par son numéro dans les échanges (ex. "question sur S07").
