Page About ALTA MALE LAB — rendu attendu et méthode Divi.

Cette page montre les 12 sections de la page About telles qu'elles doivent apparaître sur le site, en desktop et en mobile. Chaque aperçu est produit par le fichier exact à intégrer.

Un fichier = un module Code Divi. Ce que tu vois ici, c'est ce que le fichier donne une fois collé.

01 — La règle

Un fichier = un module Code.

Chaque section de la page About = un seul module Code Divi, dans lequel on colle le fichier HTML/CSS correspondant, tel quel.

Aucun module Texte, Titre, Bouton, Blog, Image ou Séparateur. Aucun réglage de style Divi (police, taille, couleur, espacement, responsive). Aucun texte retapé.

S07 (About Anthony) contient un portrait encodé en base64 (~3.8 MB) — poids normal, aucune dépendance externe. S11 : les liens CTA (href="#") sont à compléter avant mise en ligne.

02 — Réglages Divi

Paramètres à appliquer à chaque section

Réglage Valeur Note
Module Code Un module par section, pas de Row ni de Column Divi
Background #000000 Désactiver tout background Divi sur la section et la row
Padding section 0px Le padding est géré par le code HTML de chaque section
Gutter width 0 Désactiver les gouttières Divi
Max width 100% Le max-width: 760px est géré en interne
Custom CSS — Ne pas ajouter de CSS Divi — tous les styles sont dans le module
